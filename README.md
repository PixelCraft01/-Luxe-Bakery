# LUXE Bakery

**Luxury in Every Bite**

A premium, production-ready bakery website featuring Apple-level UI/UX design with glassmorphism, smooth animations, and a luxury aesthetic.

## Live Demo

Open `index.html` in any modern browser.

## Features

- **8 Fully Responsive Pages** - Home, About, Shop, Product Details, Cart, Wishlist, Contact, 404
- **Dark/Light Theme** - Toggle with localStorage persistence
- **Shopping Cart** - Add, remove, quantity controls, coupon support
- **Wishlist** - Save favorites, move to cart
- **Toast Notifications** - Real-time feedback
- **Search Overlay** - Full-screen search with keyboard support
- **Smooth Animations** - AOS scroll animations, hover effects, transitions
- **100% Responsive** - Mobile-first design
- **SEO Friendly** - Semantic HTML, meta tags, alt text
- **Accessible** - ARIA labels, keyboard navigation
- **Fast Loading** - Lazy loading, optimized SVGs
- **No Dependencies** - Only Bootstrap 5, AOS, and vanilla JS

## Tech Stack

- HTML5
- CSS3
- Bootstrap 5.3.8
- Bootstrap Icons 1.13.1
- Vanilla JavaScript
- AOS (Animate on Scroll)
- Google Fonts (Playfair Display + Poppins)
